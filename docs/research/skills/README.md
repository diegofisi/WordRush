# Skills research (2026-09-16)

Seventeen posts and articles about how people set up AI coding agents (skills, rules,
context files, loops, MCP), plus infrastructure and marketing notes the user collected
from X and blogs, read against this repo's `.claude/` setup. The sources and their
images were deleted after the reading was verified; what stays is the analysis:

- `00-resumen.md` — the summary: what it all was about, what applies now, later, or never.
- `01-contexto-limites-loops.md` — context files, constraints as files, loop engineering.
- `02-skills-mcp-ecc.md` — how others write skills, MCP vs skills, the ECC repo.
- `04-infra-latencia-sistemas.md` — latency patterns, caching, containers, system design.

The marketing / RAG / agents-guide note moved to `../otros/` (nothing to do with skills).
- `repos/` — the five repos the posts linked, cloned for reference (ignored by git).

Nothing here is a rule of the project; the rules live in `.claude/` and `docs/context/`.
