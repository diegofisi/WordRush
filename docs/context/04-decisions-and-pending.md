# 04 · Decisions and pending items

## Decisions taken (2026-09-11)

| Decision | Reason |
|---|---|
| Points come from the % of time left, not from attempts | Promote speed and chaos. Attempts only break ties (−2 each). |
| Percentage of the initial time instead of seconds | So the balance does not depend on the clock the room was configured with. |
| Position bonuses +25 / +15 / +10 (superseded on 2026-09-12 by +20 / +15 / +10) | A touch of multiplayer race, independent of the clock. |
| Keeping the hint gives +10 | So using it is a decision, not a reflex. |
| One hint per player **per round**, not per game (corrected on 2026-09-11) | The +10 for keeping it is already the cost of using it; there is no need to accumulate it across rounds. |
| Floor of 20 points for solving (superseded, see the rebalance below) | Solving is never worth less than not solving. |
| 5 points per green without solving, maximum 20 (superseded, see the rebalance below) | So whoever came close stays in the game. |
| Scoring rebalanced (2026-09-11, floor and cap superseded on 2026-09-12): attempt penalty −3 → **−2**, solve floor 20 → **30**, consolation 5 → **8** per green plus **4** per yellow, capped at 20 → **28** | Better comebacks, and solving always beats not solving. The old numbers made the two ends touch: 4 greens without solving scored 20, exactly the floor, so a player one letter short had nothing to gain from the last guesses. Now a failed round can be worth up to 28 and a yellow finally counts for something, while the floor moves to 30 so the worst solve still beats the best failure. The softer −2 makes the extra attempt that wins the round cheap, which is the point of raising the consolation in the first place. |
| Scoring simplified (2026-09-12): a flat **+40** for solving replaces the floor of 30, the cap of 28 on the consolation is gone, and the position bonus becomes **+20 / +15 / +10**. A solved round is `time % + 40 − 2 × (attempts − 1) + position + hint`, with nothing clamped; an unsolved one is `8 × greens + 4 × yellows`. `SCORING.solveBonus` replaces `solveFloor`, `maxUnsolvedPoints` is deleted, and `RoundBreakdown` swaps `floorApplied` for `solveBonus` (contract version 7). | Simpler to explain: a flat +40 for solving replaces the floor and the cap; position bonus 20/15/10. The floor and the cap were two numbers that only made sense next to each other, they had to be kept 2 points apart by hand, and both showed up on the results table as "mín." / "máx." markers over a total that then did not add up. With +40 the best possible consolation (4 greens and a yellow, 36) already sits under the bonus alone, so every row of the table is a plain sum. The first-place bonus drops to +20 so that arriving first is a nudge, not a second clock. |
| "Cambiar reglas" moves next to the settings chips (2026-09-12): in the lobby the host gets an accent-outlined "Cambiar reglas" button with a sliders icon immediately to the right of the chips row, and the chips themselves become buttons that open the same dialog. It is gone from the footer, which keeps Leave / Ready / Start. Guests see plain chips and no button. | The button sat as the second of four in the footer, far from the rules it edits, and hosts did not find it. Put next to the chips it reads as "these are the rules, this changes them", and making the chips clickable means the obvious gesture works too. |
| Automatic "−5 s al resto" ("−5 s to everyone else") attack when someone solves | Simple, everybody understands it, produces a snowball. |
| The clock resets every round | A bad round does not take you out of the rest of the game. |
| Each letter pays time only once per position | Prevents farming time by repeating letters. |
| Yellow and then green adds 10 in total, the same as a direct green | Consistency; no route is more profitable than another. |
| The same word for everyone each round | Without that the comparison is not fair. |
| No text chat, only emotes | Less toxicity, faster, Clash Royale style. |
| Stack confirmed (2026-09-11): backend NestJS 11 + Socket.IO with rooms in memory; frontend React 19 + Vite + Tailwind + Zustand. Two independent services on Railway. | The user delegated the choice; the simplest one that delivers real time and separate deployment was taken. |
| Word bank as JSON inside the backend, not in a database | Fixed, small, read-only lists; a database would be one more service with no benefit. |
| Accents ignored (limón = limon), Ñ is a letter of its own | Keyboard with Ñ in Spanish rooms; typing accents on an on-screen keyboard is awkward. |
| The hint reveals only the letter, not the position (2026-09-11) | With the position it was almost a free green; only the letter keeps the challenge. |
| Answers = base forms only, neutral Spanish, ~900 per language (870 ES / 898 EN, 2026-09-11) | Guessing "asume" against "asumo" is luck, not skill; vosotros forms and Spain-only words are not neutral. Conjugations are still valid as guesses. |
| List of valid Spanish guesses = dictionary only; no subtitle corpus (2026-09-11) | The corpus accepted English words (CLOUD) in Spanish rooms. |
| Session in localStorage and automatic re-entry while the game is still running (2026-09-11) | Closing the tab or losing internet must not take you out of the game. |
| Room lifetime: 10 min empty in the lobby (raised to 60 min on 2026-09-17), 5 min after finishing; no new round if nobody is connected (2026-09-11) | Memory hygiene; the real cost is negligible. |
| Interface language selector (ES/EN) and theme selector (light/dark) visible in the top bar of every screen | They were missing from the design; the user asked for them on 2026-09-11. The interface language is independent of the language of the room's words. |
| Leaving a room is explicit and final (2026-09-11): "Salir de la partida" in the top bar of the game and the results, with confirmation; the seat is freed, the token stops working, the round no longer waits for the leaver and the host passes to the oldest remaining connected player | A player who walks away must not freeze the round for everybody else, and a seat nobody will come back to must not hold up the room. |
| Twenty emotes behind a picker instead of a bar of six (2026-09-11): one round trigger opens a 5 × 4 grid of stickers with a "recent" row; the sender sees their own reaction burst over their avatar in the top bar | Six icons were not enough to say anything, and a permanent bar ate the space the board needs. A picker scales to twenty without taking any room, the way Facebook and iMessage reactions do. |
| Emote burst limit instead of a per-emote cooldown (2026-09-11): free until more than 8 sends inside 3 s, then exactly 5 s of pause, never longer, and the window restarts empty | A 3 s cooldown punished normal play (a laugh and a "gg" in a row) while barely slowing a spammer down. The burst limit leaves conversation alone and only stops flooding. The pause is fixed so that insisting has no cost to compute and no way to lock somebody out. |
| One game at a time per browser (2026-09-11): the home page with a live session shows a "partida en curso" card (Resume / Leave it) instead of the create and join forms; creating or joining with a live session is refused by the client and by the server (`already_in_room`); a second tab takes the seat and the older one shows "abierta en otra pestaña" with "Usar esta pestaña" | The session is a single slot. Letting somebody start a second game left the first membership dangling and made "which game do I go back to" an accident. |
| Stickers are feed messages, not avatar decorations (2026-09-11): a reaction renders as its own block in the live feed (112 px under a time + name header, consecutive ones from the same player within 10 s stacked); the bubble over the rival's avatar and the burst over the sender's own avatar are gone; phones, which have no feed, get a 2.5 s 96 px overlay above the keyboard with the sender's name | An 18 px icon in a feed line read as an emoticon; the owner wants stickers, which need room to be seen. Showing the same sticker in three places at three sizes was noise, and the feed is the only surface that keeps a history of who said what. |
| The hint never repeats a letter the player already knows (2026-09-11): it reveals a letter from an answer position that is neither green nor charged yellow; with repeated letters this is per position (one yellow `L` on `LLAMA` still allows the other `L`), and if every non-green position is already known it falls back to one of those instead of failing | Spending the one hint of the round to be told a letter you already have on the keyboard felt like a bug. Keeping it per position preserves the real information of a double letter, and the fallback means the button never refuses to do anything. |
| Guess errors are an inline caption under the current row, not a toast (2026-09-11): `word_not_in_list`, `word_length` and "not enough letters" fade in red under the row being typed for 1.6 s; every other notice stays a toast, moved to the top-right on ≥ 640 px and above the keyboard on phones | The top-centre toast sat exactly over the big clock, hiding the one number the whole screen is about. Wordle shows this message next to the board because that is where the player is looking. |
| Absent keys go darker than untried keys in dark mode (2026-09-11): `--key-gray` #4a4640 → #1a1815 with the letter at ~55 % ink (#918e89), untried keys unchanged at #2a2723 with full ink | The old grey was *lighter* than an untried key, so a letter already ruled out looked like one still to try. |
| The hint says how many times the letter appears (2026-09-11): "Hay una M en la palabra", "Hay dos L en la palabra" / "There are two L's in the word" | "Hay una L" on `LLAMA` was a half-truth: the player planned for one L and lost the round to the second. The count costs nothing to compute, the positions stay secret, and it turns the hint into information you can actually act on. |
| The host can change the room settings from the lobby (2026-09-11): a "Cambiar reglas" dialog with the same controls as the create form; host only, lobby only (`not_host` / `game_in_progress`), capacity never below the players already seated (`invalid_payload`), ready flags kept | Getting the time or the language wrong meant closing the room and asking everybody to join again with a new code. Restricting it to the lobby keeps the server the only owner of a running round, and keeping the ready flags means a rule tweak does not make everybody click "Listo" again. |
| "Jugar de nuevo" reuses the room instead of making a new one (2026-09-12): on the final results the host gets a primary "Jugar de nuevo" / "Play again" that emits `room:restart`; the server puts the same room back in `lobby` status with the same code, players (disconnected ones included), host and settings, and clears ready flags, standings, totals, attempts, hints, used words, round counter and the "finished" deletion marker. Guests read "Esperando a que el anfitrión inicie otra partida…" and keep "Salir de la sala"; the old "Nueva partida" (leave + home) is gone. Host only (`not_host`), finished games only (`game_in_progress`, "The game has not finished yet") — between rounds it is refused. | Everybody had to leave and create a room again after every game, so the code changed, the invite links died and the group had to regroup in a new lobby. Reusing the room keeps the code and the seats, and starting from the lobby (not straight into a round) means the host can change the rules first and nobody is dropped into a game they did not see coming. Only from `finished` because between rounds the server still owns a running game. |

| **Boss mode: the room against the fly, brought back as an explicitly temporary option (2026-09-17).** The old `master` experiment was merged into v1.1 with v1.1 winning every shared file, and re-wired by hand so it can be deleted in ten minutes: all of it lives in `backend/src/modules/boss/**` and `frontend/src/features/boss/**`, every line outside those folders carries the comment `// BOSS-MODE (temporary; see docs/context/07-boss-removal.md)`, and two flags (`BOSS_MODE_ENABLED`, `VITE_BOSS_ENABLED`, both defaulting to on) make it unreachable without touching code. It is offered only for the five-letter word race with no teams, which is the only board her brain and her readout know; asking for it in any other shape simply gets a room without her, and a brain that will not load leaves her standing still with a logged warning while the rest of the game carries on. Rules in `08-boss-mode.md`, removal recipe in `07-boss-removal.md`. | The owner wanted the old way of challenging the fly back for a few days without it becoming part of v1.1. Isolation is the whole point of the decision: a feature with a known removal date should cost nothing to remove, so the price was paid once, up front, in markers and in one extra module instead of being spread through the game. |


## Discarded ideas

| Idea | Why it was discarded |
|---|---|
| Points per attempt with a lot of weight (220 − 20 × attempt) | Rewarded caution. Speed is what is wanted. |
| Attack bar charged with greens (time theft, scrambled keyboard, sealed letters, fog, freeze) | Replaced by the automatic −5 s. Simpler for a first version. Can be brought back later. |
| "Fake letter" (marking in yellow a letter that is not there) | Breaks trust in the board; people stop reasoning. If it comes back, as a room option off by default. |
| A flat zero for not solving | The consolation per green (and, since 2026-09-11, per yellow) was preferred, to keep people in the game. |

## Decisions taken (2026-09-17)
| Decision | Reason |
|---|---|
| **A disconnected player is never removed from a live room.** The 60 s lobby grace is gone: somebody who is away stays listed with `connected: false`, in the lobby and in a game, and comes back to the same seat with the same session. Only leaving, a kick or the room's own death frees a seat. A room nobody is connected to is deleted after **60 minutes** instead of 10; a finished game still goes after 5. `ROOM_LIFECYCLE.lobbyDisconnectGraceMs` and the janitor's "stale lobby player" path are deleted, and with them `Room.emptiedAt`, which nothing set any more. | Real players reported disappearing from the waiting room. Sixty seconds is nothing: reading the invite link, answering a message or locking the phone is enough to lose the seat, and the room then had to be rebuilt around the person who came back. Rooms weigh a few KB, so holding a seat for an hour costs nothing next to what losing it costs. |
| **The heartbeat waits two minutes, and a short drop is repaired in silence.** Socket.IO runs with `pingInterval` 20 s and `pingTimeout` 120 s instead of the default 25 s / 20 s, and with `connectionStateRecovery` over a window of 2 minutes (`skipMiddlewares`). A recovered socket takes the "same player" path in the gateway — its seat, its channels and the events it missed — never the "new socket" one. The Nest HTTP server also gets `keepAliveTimeout` 65 s and `headersTimeout` 66 s. | The defaults drop players who did nothing wrong: a browser throttles timers in a background tab and a phone suspends them when the screen goes off, so a pong easily arrives a minute late and the server hung up on it. The HTTP timeouts are the same bug one layer down: Railway's proxy idles at 60 s, and a Node server that closes first races the next long-polling request onto a dying socket. |
| **Team mode: when every member of a team leaves on purpose, the game ends there.** The round is closed as it stands (a team that solved keeps its points, the other scores the round it played), `round:end` goes out and then `game:end` with the standings so far, and the room is marked finished so "Jugar de nuevo" works. Kicks count as leaves; **disconnections do not**, and the normal mode is unchanged. | One team cannot race nobody. Before this, the survivors played the remaining rounds alone against an empty side, winning them by default, and nothing let them stop without throwing the results away. |
| **The QR is gone; the room URL is the invitation, and every room URL is an entry point.** The invite is `/room/CODE` — the address bar's own URL — and "Copiar enlace" writes it. `/room/CODE`, `/game/CODE` and `/results/CODE` all open the join view for that code when there is no session, the "one game at a time" card when the session belongs to another room, and silently drop a dead session instead of showing "sesión expirada". `/?code=CODE` redirects to `/room/CODE` for links already sent. | A QR only helps somebody sitting next to you, and it was a canvas, a library and a dialog for that. The link is shared the way people already share links, and it is the same string the host is looking at. Making `/game` and `/results` entry points fixes the real failure: an invitation sent after the game started, or copied from the results screen, used to bounce the guest to the home page. A dead session on an invitation is not an expired session — the player never had one — so the notice was noise. |
| **Teams are changed by dragging a card (2026-09-17).** In the lobby the host can drag any player card between the two team panels and everybody else can drag their own; the arrow button on the card does the same and remains the touch and keyboard route. No new socket event: the drop emits the `team:assign` / `team:join` the button already emitted. | Clicking a slot to move was the gesture the lobby mockup promised and the one people tried first. Keeping the button means the drag is an addition, never a requirement, so touch and keyboard users lose nothing. |
| **A player with no teammates gets no own-team panel (2026-09-17).** In a 1 vs N room the solo side is not drawn; that team's clock and score sit in the centre column, where every mode already shows them. | A panel whose only row is you is a box that says "you are alone on your team". The information (clock, score) is the same one the centre column already carries. |
| **The live feed and the chat are one panel (2026-09-17).** System events, stickers and text messages share a single stream ordered by time, with the composer and the sticker trigger at the bottom; the Equipo / Todos switch shows only in team mode during the round; the same panel is used on the results screen and, compact, in the phone sheet; an arrival gets its own line. | Two columns showed the same conversation twice and neither told the whole story: the feed had the solves without the replies, the chat had the replies without what they were about. One stream is also the only layout that survives the phone, where there was never room for two. |
| **Nineteen sound cues, all synthesised, with a volume slider (2026-09-17)**, replacing the four of `06`: `roomCreated`, `playerJoined`, `playerLeft`, `gameStarted` (every round), `tileReveal`, `keyTap` (off unless "keyboard sounds" is on), `invalidWord`, `letterFound`, `letterPlaced`, `solved`, `rivalSolved`, `penalty`, `timeWarning` (10 s and each of the last five), `roundEnded`, `gameWon`, `gameLost`, `sticker`, `chatMessage` (others' only), `hintUsed`. Sine/triangle oscillators through a low-pass with short envelopes, ≈ −14 dBFS, most under 250 ms. The top bar holds mute, a volume slider (default 70 %) and the keyboard-sound toggle, all persisted. Players still cannot send sounds. | Four cues left the game silent exactly where it is fastest: a letter turning green, a rival solving, the last five seconds. Synthesising them keeps the download at zero bytes and lets each cue be tuned in code. The keyboard tap is the one cue that becomes noise if you type a lot, so it is opt-in; the slider exists because "on or off" is not a real choice with a game that talks this much. |
| **The client reconnects forever and says so with a pill (2026-09-17).** `reconnectionAttempts: Infinity`, plus an immediate retry when the tab becomes visible again or the browser fires `online`; while it is away a small "Reconectando…" pill is the whole UI change — no modal, no toast, no navigation away from the board. | The server now holds the seat for as long as the room lives, so a client that stops trying is the only way left to lose it. Retrying on `visibilitychange` and `online` is what makes coming back feel instant instead of waiting out a backoff, and the pill keeps the board, the clock and the chat on screen, which a modal would have covered. |
