# Fly model attribution

`shy-fly.glb` — **"Shy fly" by Maf'j Alvarez**, licensed **CC-BY 3.0**.

Originally published on Google Poly and mirrored through poly.pizza
(https://poly.pizza/m/8p3PASxvAQr). The file is shipped unmodified; the game
recolours it at load time and adds no geometry.

Attribution is required. Keep this file next to the model in any fork or deploy.

## A model that was tried and rejected

On 2026-09-13 this was briefly swapped for "Fly" by Kohyzazi (CC0,
https://poly.pizza/m/kCLW4c0kGx): more triangles, two real eyes, three clean
materials. On paper the better mesh; on screen a fat brown blob with hexagonal
wings. Reverted the same day. Recorded so nobody repeats the swap expecting a
different result.
